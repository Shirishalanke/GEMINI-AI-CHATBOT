
# 🤖 Gemini AI Chatbot

A simple AI chatbot built with **Streamlit** and the **Google Gemini API**.

### ✨ Features

* 💬 Chat with Gemini
* 📝 Edit & regenerate messages
* 💾 Save chat history
* 🗑️ Clear/delete chats
* 🎨 Custom UI

### 🛠️ Tech Stack

**Python · Streamlit · Google Gemini API**

### 🚀 Run

```bash
pip install streamlit python-dotenv google-genai
streamlit run app.py
```
